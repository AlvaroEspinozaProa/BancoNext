# Implementación PHP/MariaDB histórica

El login activo dejó de usar PHP/MariaDB y ahora usa Supabase Auth. La guía de
configuración está en [SUPABASE_TUTORIAL.md](SUPABASE_TUTORIAL.md).

Los archivos `legacy/bd/` y `legacy/database/` se conservan como referencia de la primera
versión del proyecto. No ejecutar ambos sistemas de autenticación al mismo tiempo.
