# Notas de la maqueta DinBank

Esta carpeta tiene ejemplos visuales. Es una idea para mirar y sacar cosas que les gusten. No cambia el trabajo de `frontend/`.

Para verla, abran `login.html`. Después de ingresar de forma simulada, pueden recorrer las demás pantallas.

## Pantallas

- `index.html`: muestra todos los accesos.
- `login.html`: ingreso y registro de ejemplo.
- `dashboard.html`: pantalla de inicio.
- `transferir.html`: ejemplo para enviar dinero.
- `ahorrar.html`: ejemplo de ahorro mensual.
- `metas.html`: metas de ahorro.
- `movimientos.html`: ingresos y gastos.
- `configuracion.html`: opciones de cuenta.

Los archivos `.css` cambian el aspecto de cada pantalla. `animaciones.js` agrega animaciones suaves. Las imágenes y el logo están en `assets/`.

Los botones, montos y formularios son de muestra. No hay usuarios reales, base de datos ni transferencias reales.
